# 사이트 설계도(PRD) — 미용실 예약문의 사이트 (샘플)

작성일: 2026-11-15 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

> 이 사이트는 미용실 원장님께 판매하기 위한 **샘플(대표 예시)** 이다.
> 한 번 잘 만든 뒤 샵 이름·메뉴·사진만 바꿔 피부관리실 등 다른 업종에도 쓴다.
> 실제 샵 정보가 없으므로 숫자·경력·후기는 지어내지 않고 "준비 중"·빈칸으로 둔다.

## 1. 한 줄 정의
인스타를 보고 온 손님이 전화 없이 예약문의를 남기고, 원장님은 관리자 페이지에서 문의를 모아 보는 미용실 사이트.

## 2. 손님
- 누가: 인스타그램에서 시술 사진을 보고 같은 스타일을 원하는 손님
- 어디서 알고 오나: 인스타그램 (프로필 링크로 접속 — 휴대폰 화면이 기본)

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 시술 가격 (커트·펌·염색·클리닉)
2. 인스타에서 본 사진 스타일로 해 주는지
3. 위치·주차

## 4. 믿게 할 증거 (실제로 있는 것만)
- 시술 전후 사진: 원장님 인스타의 실제 사진으로 채운다 (샘플에서는 사진 자리만)
- 인스타 바로가기: 더 많은 시술 사진 보기 링크
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 예약 문의하기
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로, 한 페이지)
1. 첫 화면 — 한 문장 + [예약 문의하기] 버튼
2. 시술 전후 사진 (+ 인스타 바로가기)
3. 시술 메뉴·가격
4. 위치·주차·영업시간
5. 후기 자리 (비워 둠)
6. 문의 폼

휴대폰에서는 화면 아래에 [예약 문의하기] 버튼을 늘 보이게 둔다.

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 원하는 시술 (커트 / 펌 / 염색 / 클리닉 / 기타 중 고르기)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: (미정 — 원장님께 받는다. 샘플에서는 "가격 문의" 또는 예시 표시를 분명히)
- 시간: (미정)
- 위치: (미정)
- 연락 방법: 사이트 문의 폼 (전화번호는 미정)

## 9. 이번에 넣지 않을 것
- 회원가입·로그인
- 온라인 결제·예약금
- 손님 사진 올리기 (참고 사진 첨부)
- 문의 알림 (문자·메일·카카오톡)
- 실시간 예약 달력
- 피부관리실 등 다른 업종 버전

## 10. 첫 화면 한 문장 후보
1. 인스타에서 본 그 스타일, 전화 없이 예약 문의하세요.
2. 원하는 시술만 골라 남기면, 원장이 직접 연락드려요.
3. 사진 속 그 머리, 우리 샵에서 그대로.

## 11. 다음에 할 것
- 문의 들어오면 원장님께 알림 보내기
- 참고 사진 올리기
- 피부관리실 버전 (메뉴를 "관리 프로그램", 버튼을 "상담 신청하기"로 바꾼 것)
- 다른 업종으로 바꾸기 쉽게 샵 정보(이름·메뉴·가격·주소)를 한 곳에 모아 두기
- 실제 후기 넣기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
